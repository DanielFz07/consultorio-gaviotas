## Resumen ejecutivo

Consultorio Las Gaviotas cumple los requisitos de la materia:

- 4 fases RUP con artefactos completos.
- UML detallado (clases, casos de uso, secuencia, estados, componentes, despliegue, ER).
- DSI con catálogo de excepciones, requisitos de operación y seguridad.
- Modelo físico relacional estricto en PostgreSQL 16.
- Backend funcional en Bun + Elysia + TypeScript.
- Worker de notificaciones SMTP.
- Despliegue con Docker Compose.
- Demo guionizada para presentación final.
